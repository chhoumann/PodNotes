# Security Policy

## Supported versions

Only the latest release on the
[releases page](https://github.com/chhoumann/PodNotes/releases) gets fixes.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub
[Private Vulnerability Reporting](https://github.com/chhoumann/PodNotes/security/advisories/new).
Never report a security problem in a public issue or pull request.

Include:

- the impact of the vulnerability,
- steps to reproduce it, and
- the PodNotes and Obsidian versions affected.

A fix ships as a PodNotes release, and the advisory is published with credit to
you unless you prefer otherwise.
